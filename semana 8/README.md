DRAGON BALL CRUD - SEMANA 08

1. Abre esta carpeta en Visual Studio Code.
2. Abre index.html con Live Server.
3. main.js consulta y administra los personajes mediante APIBox.
4. La pantalla muestra 5 personajes por página.
5. Con 12 personajes tendrás 3 páginas: 5 + 5 + 2.

IMPORTANTE:
Tu APIBox ya tenía registros de prueba. No ejecutes los 12 POST repetidamente porque crearás duplicados.
Si quieres exactamente 12, elimina primero los registros de prueba desde tu CRUD y luego ejecuta una sola vez los 12 POST del archivo corredores.api.http.

La tarea exige como obligatorios:
- name
- image
- race

gender se mantiene como opcional para que la interfaz se parezca a la imagen del profesor.
